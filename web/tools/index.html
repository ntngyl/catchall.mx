Check a domain's email DNS

One lookup for the four things that decide whether a domain's email works and is trusted: MX, SPF, DKIM and DMARC. Each problem comes with what to change.

Reads public DNS only. Lookups are not saved, and there is nothing to sign up for.

The four recordsWhat each one is for.

MX: where mail is delivered

MX records name the servers that accept mail for the domain. No MX record, or one pointing at a host that does not exist, and incoming mail bounces.

SPF: which servers may send

An SPF record is a list of the servers allowed to send mail using the domain. Receivers compare the sending server against it.

DKIM: a signature on each message

The sending service signs every message, and publishes the public key in DNS so receivers can check the message was not altered or forged.

DMARC: what to do with failures

DMARC tells receivers what to do when a message passes neither SPF nor DKIM for your domain: deliver it anyway, put it in spam, or refuse it. It also asks them to send you reports.

About these tools

They are part of catchall.mx, a free service that forwards every address at your domain to an inbox you already have. The same checks run on our own mail server all day, so we made them usable for any domain.

Lookups go from our server straight to public DNS. We do not keep a history of what was looked up.
