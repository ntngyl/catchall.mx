catchall.mx / DNS tools

MX lookup

See which mail servers receive email for a domain, in the order they are tried, and whether each one actually resolves.

Reads public DNS only. Lookups are not saved, and there is nothing to sign up for.

Reading the result

Each MX record has a number and a host name. The number is the priority: sending servers try the lowest number first and move to the next only if that one does not answer.

The host name must be a name, not an IP address, and it must resolve to an address itself. The tool checks both and names the mail service when it recognises it.

Common problems

Records for two different mail services

This happens when a new service is added without removing the old one. Mail then lands at whichever server answers, so some arrives and some seems to vanish. Keep one service's records.

The MX host does not exist

Usually a typo, or a trailing part of your own domain added by the DNS provider (mail.example.net.yourdomain.com). Some providers need a dot at the end of the host name to prevent that.

No MX record at all

Senders fall back to the domain's website address, which normally does not accept mail. If the domain should receive mail, it needs an MX record.

A change does not show yet

DNS answers are cached for as long as the record's TTL says, often an hour. This tool asks fresh each time the cache allows, but your own computer or provider may keep the old answer longer.
